# FIZ Game — физиканы бірге ашайық

Физика мұғалімі Төленді И.Н. жасаған материалдар жинағы: интерактивті слайдтар, виртуалды зертханалар, 3D ойындар, телефон-джойстикпен ойналатын квесттер, тесттер мен олимпиада тренажерлері.

Басты бет — `index.html`. Материалдар тізімі — `catalog.js`, файлдардың өзі — `materials/` бумасында.

## GitHub Pages-те ашу

1. GitHub-та жаңа **Public** репозиторий ашыңыз (мысалы, `fiz-game`).
2. Осы буманың **ішіндегі** барлық файл мен буманы репозиторийдің түбіне салыңыз: `index.html` репозиторийді ашқанда бірден көрініп тұруы керек.
   Файл көп (300-ден астам), ал сайт арқылы бір рет 100 файлдан артық жүктеуге болмайды, сондықтан **GitHub Desktop** ыңғайлы.
3. **Settings → Pages → Deploy from a branch → main → / (root) → Save**.
4. 1–2 минуттан кейін сілтеме: `https://<атыңыз>.github.io/fiz-game/`

## Компьютерде ашу

- `index.html` файлын екі рет басу жеткілікті.
- Телефонмен қосылатын слайдтар мен ойындар үшін `start.bat` (Python керек). Интернетсіз сынып Wi-Fi-ы арқылы ойнау үшін сол слайдтың өз бумасындағы `start.bat` файлын ашыңыз.

## Жаңа материал қосу

1. HTML файлды `materials/` ішіндегі керекті бөлімге салыңыз.
2. `catalog.js` ішіне ұқсас бір жол қосыңыз (атауы, сыныбы, жолы).
3. Сурет керек болса — `assets/thumbs/` ішіне салып, `thumb` жолына атын жазыңыз.

Оқушылардың аты-жөні бұл жинаққа енгізілмеген.
